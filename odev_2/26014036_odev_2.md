## Git Komutları
git init: Bulunulan klasörde yeni bir git reposu başlatır.

git clone <url>: Linkteki projeyi bilgisayara kopyalar.

git status: Projede nelerin değiştiğini, hangi dosyaların eklendiğini/silindiğini gösterir.

git log : Yapılan commit'lerin geçmişini  gösterir.

git add . (veya git add -A): Değişen tüm dosyaları stage'e atar.

git commit -m "mesaj": Değişiklikleri istenen mesajla birlikte kayıtlara geçirir. (-am ile hem add hem commit aynı anda yapılır baya verimli komut)

git push: Kaydettiğim değişiklikleri sunucuya (GitHub vb.) gönderir.

git restore <dosya>: Henüz git add yapmadığım, masada duran dosyadaki değişiklikleri siler, en son commit haline geri döndürür.

git restore --staged <dosya>: Yanlışlıkla git add yaptığım bir şeyi stage'den çıkarır ama dosyadaki kodlara dokunmaz (tekrar kırmızı hale getirir).

git reset --soft HEAD~1: Attığım son commit'i iptal eder ama yazdığım kodları silmez, düzenlemeye devam edebilmem için geri getirir.

git branch: Hangi branchda olduğumu ve mevcut dalları gösterir.

git switch <branch-adi>: Başka bir dala geçiş yaparım.

git switch -c <yeni-branch>: Hem yeni bir dal oluşturur hem de direkt o dala geçer.

git merge <dal-adi>: Başka bir branchdaki değişiklikleri şu an aktif olan branchla birleştirir.

## Temel Bileşenler

- Uçuş Bilgisayarı: Uçuş kontrolcüsünden gelen verilerin, ve kamera görüntülerinin işlenmesini sağlar. Güçlüdür.

- Uçuş Kontrolcüsü: Sensör verilerini değerlendirerek motorları sürmek için gerekli işlemleri yapar.Drone stabilitesini sağlar. Drone hareketlerini kontrol eder. PID burada gerçekleşir.

- Sensörler (Kameralar): Eğim, irtifa, sıcaklık, basınç vb.
  
- Telemetri Modülleri: Yer istasyonuna veri aktarmayı sağlayan modüllerdir.

- Yer İstasyonu Yazılımı

### Motor Seçimi <br>
Motorda yazan ilk 2 rakam stator çapı [mm] son 2 rakam stator yüksekliği [mm]
KV değeri : Volt başına yüksüz dönen devir sayısı.
Yüksek KV => Düşük tork, küçük pervane, yarış droneları.
Düşük KV => Yüksek tork, büyük pervane, büyük dronelar.
Yüksek KV motorlarda sarım az, direnç düşüktür bu yüzden akım çok çekilir. Çok akım ISI demektir! Çok ısınırlar.
Verimlilik gücün ne kadarının itkiye dönüştüğünü baz alır.
Düşük KV motorlar genelde daha verimlidir.

Iha'nın gözü kulağı olarak çalışırlar. Anlık konum, ivme , hız , irtifa gibi değerleri sağlayarak stabilite ve hareketin temelini oluştururlar.

### <b> PID NEDİR? </b>
Drone'un stabilitesini sağlayan matematiksel işlemlerdir.<br>
P(Orantısal): Anlık hatalara yanıt verir.<br>
I(integral): Zamanla biriken sürekli hataları sıfırlar.<br>
D(türevsel):Hatanın değişim hızını verir.<br>

GPS: Konum bulma sistemidir.<br>
RTK: Yerdeki bir istasyonu referans kabul ederek gps sapmasına düzeltme gönderir.<br>
NTRIP: Düzeltme verileri için radyo yerine internet ile haberleşme sağlar.<br>

EKF: Sensör verilerinin doğrulanmasını sağlayan algoritma.<br>

Telemetri: Iha'dan sensör, konum vb. gerekli bilgileri yer istasyonuna ileten sistemlerdir.
Telemetri seçiminde verinin şifrelenmesi ve güvenliği önemlidir. Menzil isterlerine göre seçilir. Güç tüketimi göz önüne bulundurulur.

## Modlar

1. Manuel/yardımlı mod:
 Döner Kanat:<br>
  a. Position mode: Ihayı belirli bi konuma sabitler hiç bir etkenden etkilenmeden sabit durur.<br>
  b. Altitude mode: İrtifa sabit ama rüzgar vb sürükleyebilir. Kumandadan girdi gelmeyince kendini düzeltir.<br>
  c. Stabilized Mode:İrtifayı korur. İrtifa ve konumu pilot kontrol edebilir ve kollar bırakılınca kendini düzeltir.<br>
 Sabit Kanat:<br>
  a. Position mode: Ihayı belirli bi rotada düz şekilde sabitler roll vb otomatik düzelir. <br>
  b. Altitude mode: İrtifa sabit roll pilotta.<br>
  c. Stabilized Mode:Roll ve Pitchi pilot kontrol edebilir ve kollar bırakılınca kendini düzeltir.<br>

2. Akrobatik mod:<br>
  TÜM kontroller pilotta!<br>

3. Otonom mod:
   Her şey planlı olarak yazılım tarafından yapılır<br>
   Mission: Önceden yüklenmiş görev planını (waypoint) icra eder.<br>
   Hold (Bekleme): Mevcut konumda havada asılı kalır (döner kanat).<br>
   Return (Eve Dönüş): Aracı güvenli bir irtifaya çıkarıp kalkış noktasına geri getirir ve iniş yapar.<br>
   Takeoff / Land: Otomatik kalkış ve iniş yapar.<br>
   Orbit / Follow Me: Belirlenen bir noktanın etrafında döner veya bir hedefi takip eder.<br>

OFFBOARD MODU: Uçuş kontrolcüsü kendi yazılımları yerine harici yazılımlardan genel komutları uygular (MAVLink , ROS vb.). Görüntü işleme falan uçuş bilgisayarıda ağır işlemlere yapılır hesaplamalar bilgisayarda yapılıp controllere gider.
